### 学习路线推荐

**前端入门路线**：
1. `bootstrap` → 掌握响应式布局与基础组件
2. `Vue` → 学习渐进式框架的核心概念
3. `项目案例` → 通过实战巩固所学知识

**后端拓展路线**：
1. `Node.js` → 了解服务端 JavaScript 开发
2. 结合 Vue + Node.js → 前后端全栈开发
