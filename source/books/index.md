## 我的书架

这里记录我在学习和成长过程中读过的优秀书籍，涵盖前端、后端、数据库、软技能等多个方向。

---

### 前端开发

- **《JavaScript高级程序设计（第4版）》** - 红宝书，JavaScript 进阶必读
- **《你不知道的JavaScript》** - 深入理解 JS 核心机制（上中下三卷）
- **《Vue.js设计与实现》** - 霍春阳著，深入理解 Vue 3 框架设计思想
- **《深入浅出React与Redux》** - React 学习参考
- **《CSS世界》** - 张鑫旭著，前端 CSS 进阶
- **《深入解析CSS》** - CSS 规范解读

### 后端开发

- **《Spring Boot实战》** - Spring Boot 入门与实践
- **《Spring源码深度解析》** - Spring 框架原理
- **《MyBatis从入门到精通》** - MyBatis 持久层框架
- **《深入理解Java虚拟机》** - JVM 圣经
- **《Java并发编程实战》** - 多线程与并发
- **《Redis设计与实现》** - Redis 原理与源码

### 数据库

- **《MySQL必知必会》** - MySQL 入门经典
- **《高性能MySQL》** - MySQL 性能优化
- **《SQL必知必会》** - SQL 速查手册

### 计算机基础

- **《计算机网络：自顶向下方法》** - 网络协议入门
- **《操作系统概念》** - 操作系统原理
- **《算法导论》** - 算法经典教材
- **《数据结构与算法分析》** - Java 语言描述

### 软技能 & 其他

- **《代码整洁之道》** - 写出优雅的代码
- **《重构：改善既有代码的设计》** - 重构经典
- **《设计模式：可复用面向对象软件的基础》** - GoF 四人帮
- **《人月神话》** - 软件工程管理经典
- **《程序员修炼之道》** - 程序员职业素养
