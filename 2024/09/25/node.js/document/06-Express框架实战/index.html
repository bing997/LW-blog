一、Express 简介

1.1 框架特点

Express 是 Node.js 平台上最流行、最成熟的 Web 应用框架，具有以下特点：

特点 说明
轻量级 核心功能简洁，无冗余设计
中间件架构 强大的中间件生态，灵活扩展
路由系统 清晰的路由定义，支持 RESTful 设计
模板引擎 支持多种模板引擎（EJS、Pug、Nunjucks 等）
生态丰富 npm 上有大量 Express 中间件和插件
文档完善 官方文档详尽，社区活跃
